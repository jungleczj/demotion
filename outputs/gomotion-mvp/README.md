# GoMotion 风格 · 本地 MVP

这是用于验证“脚本 → 素材匹配 → 成片”的独立本地原型。界面参考 GoMotion 的工作台与教程布局，不连接 GoMotion 服务。

## 直接打开

本次会话地址：**http://localhost:3027**

1. 使用示例脚本，或粘贴自己的中英文旁白。
2. 在 Visuals & options 中选择主题，也可使用自动识别。
3. 点击 Generate video。每个镜头会检索实际素材目录，候选结果保留来源、作者、尺寸和许可信息。
4. 已启用视觉 AI 时，会分批读取低清候选，不通过时补搜，按实际配音时长选择素材和取段，并规划整片剪辑。旧项目点击“AI 看画面并重新选材”。
5. 在编辑器选择镜头，点击 Replace。可以改关键词、搜索视频、预览候选、上传自己的素材。
6. 满意后点击 Export video。生成 1080p MP4，并提供 SRT 字幕和素材来源 JSON。

## 视觉 AI 配置与使用

在“设置与连接 → AI 服务 → 视觉 AI”配置 Gemini 或兼容多图的模型接口。文字规划默认与视觉选材共用 Gemini，独立文字接口可另行配置；密钥仅保存在当前服务内存中。

- Gemini：将低清视频作为原生视频输入发送给模型；默认模型 `gemini-3.8-flash`，可按账户支持情况修改。
- 兼容接口：将 10 张带原视频时间戳的抽帧作为多图输入。稀疏抽帧不能保证动作连续性。
- 新项目检索完成后自动运行；旧项目可手动运行。AI 返回的资产 ID 和时间段在服务端验证。
- 先生成并测量真实神经配音长度；AI 选择足够覆盖旁白的区间。手动锁定的素材与起点保留。
- 导出后自动审查实际画面与声音，返回问题时间、镜头和建议；未通过时仅提供草稿预览。
- AI 执行记录展示模型、真实输入类型、耗时、token 用量与失败情况。配置完成不等于模型调用已成功。
- 本轮没有自动发起模型生成/审片或功能测试。首次实际使用的权限、额度及结果需在界面中查看。

### 容量和范围

每镜头最多 4 批、每批 2 段，单次最多 12 镜头。视频预览每段下载最多 24MB，候选分析读取累计最多 96MB。候选只分析前 60 秒；成片分段检查完整时长。缓存容量与处理范围见文末。

视觉任务最多 36 次模型调用、15 分钟；手动审片最长 5 分钟。模型使用你账户额度；token 记录不是精确费用账单。没有完整覆盖就停止制作；失败保留原项目，不报告制作完成。

当前按镜头分别生成 Gemini 神经旁白，没有整篇声音表演、逐词对齐、自动背景音乐或自动修订循环。视觉模型对实体、动作和时间点的判断仍需人工预览。

- 中英文脚本规划、英文检索词、素材目录重排序：默认使用已配置的 Gemini。独立文字接口可使用 OpenAI 兼容 API。未配置/失败时明确回退到句子拆分和关键词规则，不伪装 AI 结果。
- 整片选材：按主题检索最多两个来源，由视觉 AI 查看低清候选并规划实际取段。旧的色彩规则接口仅保留为基础工具，不作为视觉 AI 的替代路径。
- Coverr 只接收 API 标记为免费且非 AI 的视频，并展示署名与回传选用统计。Pixabay 使用 film 分类过滤，不能据此保证排除全部 AI 内容。
- 配音：Gemini 神经配音 Kore / Charon / Puck，试听、测时、导出共用真实音轨。
- 视频预览、镜头起点、预计时长、横竖屏、满屏裁切/保留全幅、字幕、项目列表与 JSON 下载。
- 素材按需下载检查，原始下载转码后删除，保留有限容量的兼容视频缓存。导出文件与上传文件临时保留 24 小时。

## 有意保留的限制

- 目录初筛基于标题和说明，视觉 AI 另外读取实际媒体。视觉推理不能自动证明历史事件、具体人物与地理位置准确，也不保证逐帧识别。
- 不提供 YouTube 抓取；可在外部合法取得素材后手动导入。
- 单次脚本 15–5,000 字符，最多 12 个镜头。上传单文件最多 90MB，远程预览最多 24MB。找不到完整覆盖素材时停止本次制作，自动补搜不以无关画面充数。
- AI 选材按真实音轨测时。编辑器逐镜头预览，完整转场见生成后的成片播放器。素材长度不足就停止导出，不从头循环。
- 字幕在每段旁白内分块均匀显示，不是逐字语音对齐。背景音乐和高级动态图形暂未实现。
- Internet Archive 的检索结果并非全部可复用；NASA/Commons 的材料也应查看单条来源说明。导出附带来源清单以便核对。
- 项目保存在当前浏览器 localStorage，最多保留 25 条。浏览器清理数据后不会自动恢复；可下载 JSON 留档。当前仅提供项目 JSON 导出，没有项目 JSON 导入。
- API key 只保留在本地服务内存，前端不会收到密钥，也不会将其写入源码或项目文件。服务重启后需重新配置。`.env.example` 只提供占位说明，未写入用户密钥。
- 此原型绑定 `127.0.0.1`，用于本机验证，没有生产身份认证或托管部署。

## 本地启动

需要 Node.js 25.4+、FFmpeg、ffprobe，以及具备 TTS 和视频分析权限的 Gemini key。本次环境已具备这些依赖。

```sh
cd /Users/chenzhijiang/Documents/Codex/2026-11-09/gomotion-market-research/outputs/gomotion-mvp
npm install
npm run dev
```

默认端口 3027。可通过 `PORT` 修改端口。已有服务运行时不要重复启动同一端口。

生产构建和本地运行：

```sh
npm run build
npm start
```

设置入口在左侧“设置与连接”。填写新 key 后点击“保存连接”，再勾选对应素材来源。可以配置任意兼容 Chat Completions 的服务地址、模型与 key。

## 结构

- `src/components/Creator.tsx`：创作表单。
- `src/components/Editor.tsx`：预览、时间轴、镜头编辑与导出任务。
- `src/components/AssetPicker.tsx`：真实候选、搜索、预览与上传。
- `src/catalog.ts`、`src/research.json`：主题路由与独立调研资料。
- `server/sources.mjs`：素材提供方适配、元数据缓存与排序。
- `server/planner.mjs`：AI 镜头规划与目录重排序、明确的规则回退。
- `server/vision-client.mjs`、`server/vision-media.mjs`、`server/visual-director.mjs`、`server/visual-review.mjs`：视觉模型、受限媒体读取、AI 取段与成片审查。
- `server/sequence.mjs`：小缩略图特征与整片候选组合选材，无候选视频预下载。
- `server/render.mjs`：旁白、字幕、视频归一化和 MP4 合成。
- `server/index.mjs`：同源 API、媒体代理、上传与导出任务。

临时文件位于系统临时目录下的 `gomotion-local-mvp`。元数据缓存不包含 API key。

## 2026-11-10：可播放素材、完整覆盖与声音要求

- 复现：Commons 珊瑚礁原文件返回 429，官方 480p derivative 返回 206。原版只透传原文件，且把失败统一隐藏成“无法播放”。
- 视频列表现在先下载并完整解码候选，规范为 H.264 / yuv420p / faststart MP4，通过后才列入可选素材。一次显示最多 6 段，检查前 12 个目录候选；失败的自动排除。旧项目素材列表同样重新检查。
- 预览、AI 看画面、导出共用已解码视频，来源站限流不会导致三条链路各自失败。Commons 使用官方 videoinfo derivatives，而不是拼接推测地址。原片不提前建库。
- 视频文件每段最多下载 24MB、时长 2–300 秒，兼容视频缓存不超过 256MB，最多并行处理 2 段；缓存中刚使用的文件保留 5 分钟。超过范围的候选不会加入可选列表。导出为 1080p 画布，源预览可能只有 360p/480p，不能视为原生 1080p 清晰度。
- AI 每批看 2 段，不匹配时自动补搜及更换候选，每镜头最多 4 批，整次最多 36 次模型调用、96MB 候选分析读取。没有完整覆盖就停止制作，不再以“已完成”保存缺镜头成片。动态视频是硬要求，不接受静图填充。
- 新项目使用 Gemini `gemini-2.5-flash-preview-tts` 神经配音（Kore / Charon / Puck），旧项目重新打开时升级声音并要求重新选材。该模型有免费层，实际额度和费用取决于账户方案；没有额度时明确失败，不回退到 macOS 或浏览器朗读。
- 试听、测时和导出使用同一份按文本及声音缓存的真实 WAV，音频缓存最多 96MB。当前按镜头生成，段落级语气连续性仍需试听。
- AI 给出切换/短叠化选择，渲染实现实际 xfade；叠化通过轻微延长已审核画面实现，不额外借用未审核素材。配音不重叠，字幕合成在转场之后。编辑器是逐镜头素材预览，最终播放器才包含真实转场。
- 导出后自动读取完整成片的画面和声音，按 60 秒分段审查（不再只检查前一分钟），检查文不对题、空白、静图、转场、漏读、发音、停顿与机械感。未通过的只提供草稿预览；通过后显示最终下载。AI 审片不能替代人工审看和试听。
- 完成了类型、语法与生产构建检查；已用实际 HTTP/视频解码诊断修复媒体读取。没有运行测试套件，也没有自动调用 TTS 或重新制作海洋项目，因此不宣称已验证整片主观效果。

## 2026-11-10：草稿部分预览与时长修正

- 缺镜头不再锁住整个播放器。默认从当前位置连续预览已有视频，自动跳过未选镜头；全部播放后结束。前台明确显示草稿和缺失数量，跳过的段落不作为完整成片交付。
- 不完整选材任务保存已通过的镜头，状态为 `incomplete`，不标为成片完成；整片导出继续要求每句台词都有经过确认的动态画面。
- 缺失镜头或尚未准备统一旁白时，可先静音预览已有画面，不因旁白准备失败阻断已有视频。准备好统一旁白后，再次播放使用同一音轨的对应区间。
- 删除旁白测时、渲染和编辑器中的 45 秒硬限制。规划阶段会按词与语义边界拆分长段落，原脚本内容保留；现有单次 12 镜头规模仍适用，较长内容可保留更长镜头。
- 候选原生视频读取范围根据真实镜头时长扩展，最长覆盖素材可用的 300 秒；超过一分钟时降低分析尺寸和码率，保持输入容量上限。不能拿未审核的后续视频补时长。
- 实际缓存音轨发现 27、33 秒等异常静音。新增仅压缩超过两秒的异常静音处理，保留正常停顿；原录音保留，升级缓存可复用原录音，无需重新调用生成接口。实例由 153.37 秒缩至 82.19 秒，这只是静音处理结果，不代表已确认全文语义或自然度。
- 配音处理版本升级，旧项目的时间对齐缓存不会冒充新处理后的结果；需要按处理后的音轨重新对齐。
- 本轮完成类型、语法及生产构建检查，并处理了现有音轨以核对静音问题；未运行测试套件，未自动重新生成整片。


## 2026-11-10：有限自动补片

## 声音验收命令（2026-11-11）

在已配置且空闲的本机 3027 服务上运行。脚本只通过本机 `/api/narration` 访问已配置的服务，不读取或打印密钥，也不会启动或重启服务。

```sh
# 只查看任务计划，不发送请求

node scripts/verify-voices.mjs --resume

# 仅重新验证失败/未运行项，保留成功证据
node scripts/verify-voices.mjs --run --resume
```

真实运行共 44 项、最多两项并发。声音、语言代码和示例文本来自共享目录；已有成功项在续跑时不再请求。每个返回的本地 WAV 下载到独立系统临时目录，经 `ffprobe` 测量真实时长，再用 FFmpeg 解码完整音频。API 可能复用服务端缓存，脚本不会将所有响应都声称为首次生成。

结果写入应用目录外的 `../voice-live-acceptance-2026-11-11.json`。真实续跑前，当前报告会按其轮次复制为 `../voice-live-acceptance-roundN-2026-11-11.json`，例如第三轮开始前保存 `round2`；已有轮次备份不覆盖。结果包含逐项成功、失败、未运行、文件路径、时长、解码状态，以及本轮与累计统计。

本机接口返回 402 / 403 / 429（包括错误中携带上游状态）时立即停止派发；其他连续三次失败也停止，成功会重置连续失败计数。正在进行的另一请求会被客户端取消，不能据此断言服务端已经取消或没有计费。脚本不自行循环；`429` 本身不能确定是每日额度问题。

**完整解码通过不代表浏览器能播放，也不代表语言、音色身份或自然度通过听验。** 这些字段保留为 `not_assessed`。实际浏览器验证、音频听验及其余任务状态以[任务清单](../../TASKS.md)和最新结果报告为准。历史交付段落中的旧限制不作为本轮验收结论。
