## 同稿验收方法

| 基线 | 验收要求 |
|---|---|
| 输入身份 | 保存实际取得、可供使用的完整英文原稿及SHA-256、长度、段落索引；不翻译或改写后声称同稿。 |
| GoMotion参考 | 优先取得这份稿的实际成片与选项；教程中的其他项目只能作为风格参考，不作为逐句配对。 |
| 覆盖与一致性 | 原文和叙事顺序保留，旁白无遗漏；全片同一声音；100%时间轴有可播放画面；统一画幅、清晰度和字幕。 |
| 内容 | 按原稿事实段落核对人物/舰船/年代/事件/动作；区分实拍、背景镜头和有依据的图文动效，不用相似武器冒充特定型号。 |
| 图文表达 | 从真实素材与数据形成地图、证据板、要点、图表和标题；所有元素有来源；不要求用户补分镜指令。 |
| 视听 | 逐边界检查闪屏、配音断裂、字幕重启、音乐突跳；实际浏览器及导出均验收。 |
| 性能 | 全流程提交到审片结束计时，记录冷/热缓存、各阶段耗时与重试；目标2倍，不能用恢复任务冒充冷启动。 |
