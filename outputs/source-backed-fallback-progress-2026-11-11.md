# 第11项：以真实非视频素材补齐镜头

2026-11-11。实现与本地验证已推进，真实失败项目的新版完整成片仍待验收。

## 当前链路

1. 从已启用的图片来源检索候选，每个缺口最多核对4个；下载实际文件，记录作者、许可、来源页和 SHA-256。
2. 完整解码原文件，保留原件；只在最长边超过1600时缩小整幅画面，供视觉审查与渲染共用。不裁去内容、不放大、不擦来源标记。实际尺寸及原/解码文件哈希一并保留。
3. 视觉审查必须读取实际图片，确认对象、画质、水印、语义及与当前旁白的关系。只能使用图片中有证据的区域和旁白原文标签。
4. 动效保留整幅真实基底，通过定位高亮和标签揭示组织画面。不能自行捏造主体、动作、关系或统计数字；没有足够视觉证据的候选不通过。
5. 与全片统一画幅和风格，再接受最终实际视频与声音审查。4路素材获取/审查、2路图形渲染；每个完成镜头保存检查点。

## 防止旧缓存绕过

- [来源门槛](gomotion-mvp/server/source-provenance.mjs)要求 schemaVersion=2、精确 scene ID 和旁白绑定、来源及许可、真实读图证据、区域标注和处理计划一致。
- 恢复任务、复用成片、导出和审片都核对实际源文件是否存在且哈希一致。原文件被删、被替换或旁白已修改时不能继续复用。
- 旧版自行绘图样片不能充当本项通过证据；真实视频素材不受图形来源凭证的额外要求影响。
- 取消只中止自己的媒体订阅；最后一个订阅取消后才停止共用下载/转码，避免重复下载与取消互相干扰。
