# Visual AI Implementation Plan

> **For agentic workers:** Use inline execution in the current session. No delegation is needed.

**Goal:** Feed real candidate media to a visual model and return source-bound shot intervals and a project-level edit plan.

**Architecture:** Independent vision configuration supports native Gemini video and OpenAI-compatible timestamped image inputs. Async jobs expose progress and cancellation; only registered assets are read, with bounded temporary media and cleanup. A model chooses intervals; the server validates IDs, time ranges and locked selections.

**Tech Stack:** Existing Node HTTP, React/TypeScript, FFmpeg, native fetch.

**Spec:** `outputs/mvp-ai-pipeline-review-2026-11-10.md`; user explicitly requested implementation.

## Global Constraints

- No video archive: at most 2 candidates per scene, 24 unique candidates, 12 MB per remote preview, 96 MB per job.
- Candidate analysis covers at most the first 60 seconds; disclose this boundary.
- No model key is written to files or returned to the client.
- Missing/failed vision service is explicit; no rules masquerading as visual AI.
- Do not add or run tests unless the user requests them. Use builds/type checking only.
- Actual paid calls require usable user-supplied vision configuration; no unrelated credentials.

## Review Focus

- Unknown or invented asset IDs and unsupported time intervals are rejected.
- User-locked clips and source offsets stay unchanged.
- Cancellation and failures remove temporary media.
- Model failures preserve the existing project and expose stage status.
- Download ceilings and omitted/unreadable candidates are visible in the job report.
